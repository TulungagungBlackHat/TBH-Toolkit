## 🚀 Install 1 Klik

**Termux / Kali / Linux:**
```bash
git clone https://github.com/TulungagungBlackHat/TBH-Toolkit
cd TBH-Toolkit
bash install.sh
```

**Atau langsung:**
```bash
curl -sSL https://raw.githubusercontent.com/TulungagungBlackHat/TBH-Toolkit/main/install.sh | bash
```
